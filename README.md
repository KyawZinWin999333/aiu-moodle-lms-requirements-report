# AIU Moodle LMS Requirements Engineering Report

This repository stores supporting artefacts for the CCE2233 Requirements Engineering individual assignment.

## Project Title
Requirements Engineering Analysis Report for AIU Moodle LMS

## Supporting Artefacts
- Use case diagram created using Draw.io
- System context diagram created using Lucidchart
- Jira Kanban board screenshot for workflow management
- AIU Moodle LMS observation screenshots
- Tool usage evidence

## Purpose
The repository was used to organise report-related files and provide simple version control for the supporting materials used in the requirements engineering analysis.
